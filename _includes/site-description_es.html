Esta es una muestra de un sitio hecho con Refracta: una herramienta de código abierto para generar catálogos digitales de bajo costo para colecciones artísticas y de patrimonio digital.

Refracta es una implementación de MOREL para objetos digitales de valor visual. Ensambla servicios gratuitos de almacenamiento (Archive.org/Wikimedia Commons), gestión de bases de datos (Zotero) y ejecución de eventos y tareas (GitHub Actions), para facilitar la gestión de catálogos digitales a galerías pequeñas, artistas independientes e instituciones públicas desfinanciadas.

Refracta permite organizar las obras en listas dinámicas, agrupándolas de acuerdo a características en común como:

  • artistas
  • lugar
  • año

Además tiene un motor de búsqueda que permite encontrar obras directamente por palabras clave.
